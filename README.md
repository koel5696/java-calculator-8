# 문자열 덧셈 계산기

---

## 개요

---

※ 입력한 문자열에 구분자를 기준으로 숫자를 분리하여 덧셈을 구현한다.

---

## 🛠 구현할 문제

---

1. (,)와 (:) 콜론을 구분자로 가지는 문자열을 구분자를 기준으로 분리해 덧셈을 실시한다.

    ```jsx
    ex) 1,3:4 ⇒ 7; 2;50;200 ⇒ 252
    ```

2. (,)와 (:) 콜론을 제외한 커스텀 구분자를 지정할 수 있다. 문자열 맨 앞에 “//” 와 “\n”을 사용해 사이에 있는 구분자를 커스텀 구분자로 사용한다.
    - “//%\n1%2:3이 입력되면 커스텀 구분자 %도 구분자로 받아들여 계산결과 6이 출력된다.

## ✅ 검증 사항

---

1. 아래에 해당하는 입력이 들어오면 IllegalArgumentException을 발생시킨 후 종료시킨다.
    - 지정되지 않은 구분자가 사용된 입력
    - 커스텀 구분자로 지정되지 않은 숫자가 아닌 입력
    - 정수가 아니며 Long타입 범위를 넘어서는 입력
    - 커스텀 구분자가 여러개 입력
    - 숫자가 구분자로 입력

    ```jsx
    // 아래의 코드와 일맥상통하는 입력은 모두의 예외를 발생시킨다.
    
    //;\n1;4)5 ⇒ error
    // \n1 A 3 ⇒ error
    //^\n1^^4 ⇒ error
    //&&\n2&&4&&5 ⇒ error
    \\%\n2%1%4 ⇒ error
    ```

## ❗ 유의 사항

---

1. 음수의 입력은 모두 정상 계산된다.
    - 단, 커스텀 구분자가 (-)로 들어오는 경우 — 패턴이 나왔을 시 다음 구분자가 나올 때까지 확장하여 확인.
        - ex) //-\n2—3:5 ⇒ 구분자를 기준으로 수를 분리하되, — 패턴 등장 시 3 다음 등장하는 구분자까지 연장하여 확인.
2. 공백(space입력)도 커스텀구분자로 받아들인다.

## 상세 기능 구현 목록

---

1. 사용자에게 계산을 진행할 문자열을 입력받을 기능을 만든다.
2. 입력받은 문자열을 컨트롤러가 전달받아 기본적으로 유효한 입력인지 판단하는 기능을 만든다.
3. 기본 문자열 입력이면 바로 split를 진행한다(6번 시행).
4. 커스텀 구분자를 지정하는 입력이 포함되면 커스텀 구분자 입력을 검증한다.
5. 그 뒤 문자열이 커스텀, 기본 구분자를 올바른 형식으로 사용해 구분했는지 검증한다.
6. 분리된 각 숫자가 07 등과 같은 올바르지 않은 숫자 형식인지 검증한다.
7. 문자 형식이나 소수 등 올바르지 않은 형식인지 검증한다.
8. 음수인지 검증한다.
9. 모든 검증이 끝나고 숫자의 합을 반환한다.
10. 최종 합 결과를 반환한다.
